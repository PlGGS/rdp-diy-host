rdp.diy Host is running

If you downloaded this installer from the rdp.diy console, this Mac is already in your team. Connect to it from rdp.diy with the password you chose.

Allow rdp.diy Host under System Settings › Privacy & Security › Screen & System Audio Recording and Accessibility when asked. Both are needed to see and control this Mac.

Installed it another way? Create a deploy token under Add a device, then run in Terminal:
sudo rdpdiy-host --deploy --token <token>
sudo rdpdiy-host --password '<password>'

To remove it later: sudo /Applications/rdpdiy-host.app/Contents/Resources/uninstall.sh
